CLUB BOSS 27 — ANDROID-READY WEB APP PACKAGE

Contents:
- index.html: the current full manager-mode game
- manifest.webmanifest: app name, icon and install display settings
- service-worker.js: offline cache support
- icon-192.png and icon-512.png: app icons

Important:
This is a Progressive Web App (PWA) package, not an APK yet.
For Android's install prompt and offline caching, the files must first be hosted
on a secure HTTPS website. After that, the site can be installed from Chrome.
A Play Store release or standalone APK requires an additional Android packaging
and testing step.
